審査アクセス説明

APIクライアントについて

ホロマドのAPIクライアントは、運営者が内部で使用する非公開の収集・分析ツールです。YouTubeの公開情報を取得し、週間の動向分析と動画制作に利用します。このサイトは説明ページであり、実クライアントの実行・操作画面ではありません。

OAuthは利用していません。一般利用者向けのGoogleログインやデモログイン、デモアカウントはありません。

審査資料について

追加の機能説明や動作記録が必要な場合は、審査担当者からの求めに応じて、指定された方法で提供します。

データの取得、保存期限、削除依頼などについては、プライバシーポリシーをご確認ください。保存期限の管理と定期的な削除処理は本番環境で運用しています。

For reviewers

HOLOMADO is operated by an individual. Its API client is a private internal tool that collects public YouTube information for weekly analysis and video production. This website provides project information; it does not provide access to the API client.

The client does not use OAuth. There is no end-user Google login, demo login or demo account. Additional explanations or demonstration records can be provided upon request through the channel specified by the reviewer.

The privacy policy (Japanese) describes data handling and deletion requests. Retention controls and scheduled deletion processes are in production operation.
