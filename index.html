ホロマド（HOLOMADO）は、ホロライブ関連チャンネルの公開情報を収集・分析し、週間ランキング・情報番組の制作に利用する個人運営プロジェクトです。

このサイトでは、プロジェクトの概要と利用条件をご案内しています。

公開情報から、番組制作へ

YouTubeの公開情報 → 週間の動向分析 → ランキング・情報番組の制作

YouTube API Servicesを利用しています。 公開されている動画・チャンネル情報を収集し、週間の動向を分析して番組制作に役立てます。制作には動画サムネイルやチャンネルアイコンも利用します。

分析と開発の現状

週間の再生数・登録者数の増加、比率、合計、配信時間などを集計・分析し、番組制作に利用しています。分析結果は運営者による独自算出であり、YouTubeが直接提供する指標や公式評価ではありません。

プロジェクトは開発中です。仕様や提供内容は変更される場合があります。将来的に番組動画の広告収益化を予定しています。

この説明サイトには、アカウント登録、ログイン、広告、埋め込みプレイヤーを設置していません。
