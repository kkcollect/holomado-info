1. 運営者と対象

ホロマド（HOLOMADO）は個人が運営します。本ポリシーは、説明サイト、非公開の収集・分析基盤、および動画制作工程での情報の取り扱いを説明します。お問い合わせ先は kkcollect590@gmail.com です。

2. YouTube API Servicesの利用

ホロマドはYouTube API Servicesを利用します。Googleによる情報の取り扱いは Googleプライバシーポリシー、YouTubeの利用は YouTube利用規約 をご確認ください。

3. 取得する情報

YouTubeで公開されている動画・チャンネル・プレイリスト情報を取得します。動画・チャンネルID、名称・タイトル、説明、公開日時、再生数・高評価数・コメント数・登録者数・動画数、動画の長さ、公開状態、配信開始・終了日時、言語・地域・タグ・カテゴリ・トピック・ブランディングなど、利用APIが返す公開メタデータが対象です。返却されない項目もあります。コメント本文は収集しません。

動画制作には、公開されている動画サムネイルやチャンネルアイコンを利用します。また、運営者が作成・管理する分類情報などを併用します。

一般利用者のGoogleログイン、OAuthによる非公開アカウントデータへのアクセス、パスワードや決済情報の入力機能はありません。Google・YouTube等のパスワード、APIキー、認証トークンをお問い合わせに送らないでください。

お問い合わせの際は、送信者のメールアドレス、本文、添付、対象URLおよび対応記録を取り扱います。回答と依頼対象・権限の確認に必要な範囲で利用します。

4. 利用目的

公開情報の収集・検証、障害復旧、週間動向の分析、ランキング・情報番組の試作と制作、品質確認、お問い合わせ対応に利用します。独自に算出する分析指標と統計データは、YouTube API Servicesの適用条件に従って取り扱います。

5. 保存場所と共有

取得した情報は、運営者が管理するデータベース、クラウドストレージおよび動画制作環境に保存し、ランキングの集計、動画制作、品質管理、障害復旧に利用します。保存や処理には外部サービスを利用しており、その提供事業者がサービス提供に必要な範囲で情報を処理する場合があります。収集データや認証情報へのアクセスは必要な範囲に制限して管理します。

番組動画には、選定した公開タイトル・名称・画像・統計や分析結果が含まれる場合があります。生の収集データ一式や認証情報をこの説明サイトから提供することはありません。公開する情報は、適用される規約と権利関係に従って取り扱います。

以下の保存・削除方針は YouTube Developer Policies と 派生指標・データ保存の追加ポリシー を参照しています。

6. 保存期間・更新・削除

YouTube API Servicesから取得した情報には、取得日を基準とする保存期限を設定します。通常の保存条件が適用されるAPIデータは、YouTube Developer Policiesに従って更新または削除し、30暦日を超える無条件の保存は行いません。現在値として更新可能な情報は必要に応じて再取得し、期限切れデータは集計・動画制作などでの利用を停止します。

保存期限の判定、期限切れデータの利用拒否、定期的な自動削除、および削除済みデータの再利用防止を運用しています。取得日を基準とした期限は、コピー、復旧、再集計によって延長しません。データの種類や処理目的に応じて、通常の上限より短い内部期限を適用する場合があります。

統計情報や独自に算出する指標の長期保存については、YouTubeの追加ポリシーに基づく利用条件と必要な受理・承認の範囲内でのみ適用します。長期保存の条件が適用されない情報には通常の更新・削除規則を適用し、タイトル・名称・説明・画像などの保存期間を一律に延長することはありません。

保存期限の管理は収集・復旧・集計・動画制作の各処理に組み込まれています。期限に達した情報の利用を制限し、定期処理による削除と再投入防止を行います。削除対象の確認と処理結果の記録を通じて、保存データの管理を継続します。

保存期限と削除の管理は、関連する保存先や動画制作工程で扱うデータにも適用します。

問い合わせ情報：メールアドレス、本文、添付、対象URL、対応記録を、お問い合わせへの回答や依頼対象・権限の確認に必要な範囲で利用し、対応完了後90日以内に削除します。

7. お問い合わせ・削除依頼

kkcollect590@gmail.com 宛てに対象チャンネル／動画URLと依頼内容をお知らせください。必要最小限の範囲で対象・権限を確認します。パスワード、APIキー、認証トークンは送らないでください。

削除依頼への対応：対象データと依頼内容を確認し、適用されるYouTube Developer Policiesに従い、対象となる削除依頼には原則として受領から7暦日以内に対応します。必要な削除または利用停止を行い、結果を原則メールでお知らせします。

ホロマドが保存したデータを削除しても、YouTube上の元動画・チャンネル・データは削除されません。YouTube上のデータの削除はYouTube側で行う必要があります。

現在の構成では一般利用者向けOAuth認可を利用しません。Googleアカウントに許可したアプリの確認・取り消しは Googleのアクセス権管理 で行えます。将来OAuthを導入する場合は、認可取得・取り消し・削除手順を本書に反映します。

8. サイト閲覧・Cookie・外部リンク

この説明サイトには独自のCookie、アクセス解析、広告、外部フォント、埋め込み動画、アカウント登録を設置していません。サイトの配信に利用する外部サービスの提供事業者が、配信やセキュリティ管理のためにIPアドレスなどのアクセス情報を取り扱う場合があります。

リンク先へ移動した後は、そのサービスのポリシーに基づき情報が処理されます。将来、広告・埋め込み・分析機能を追加する場合は、実態に合わせて本書を更新し必要な対応を行います。

9. 安全管理と変更

認証情報は非公開の運用環境で管理し、アクセスを必要な範囲に制限します。この説明サイトには認証情報やAPI接続機能を組み込みません。取り扱いを変更する場合は、内容と改定日をこのページでお知らせします。
